# Voca 3.0.0 Release Notes

## Overview

Compared with 2.0.0, Voca 3.0.0 replaces the galaxy's earlier search presentation with a static timeline wall, adds a bundled technical glossary to dictionary lookup, and makes workspace and galaxy navigation more deliberate. The interface also gains English and Simplified Chinese resources with a user-selectable language preference.

## Search as a timeline wall

- **Position entries by their last save time.** The fullscreen search view lays library entries out from older to newer in rows. Long inactive periods contribute at most **14 days** to layout spacing; overlapping labels move to another row rather than shrinking text. When there are more rows than fit, the time axis extends beyond the screen so labels remain readable.
- **Read activity at a glance.** A word's font size grows with its save count, up to an extra **10 pt**. A bottom date ruler draws major labeled ticks and shorter minor ticks, with date granularity adapted to the span shown.
- **Navigate without losing your place.** Drag or two-finger pan horizontally; zoom with the wheel or pinch around the pointer, up to **8×**. Click an entry for its details and actions, double-click it for lookup, or double-click empty space to reset the view.
- **Keep the sphere where it belongs.** The library and clipboard modes still use the rotatable word sphere. The menu bar opens timeline, library, or clipboard directly; galaxy settings are accessible there, while usage instructions move to **Help → Voca Help**.
- **Set the atmosphere without obscuring the wall.** The timeline's frosted background can be adjusted from **30% to 100%** (default **70%**). The galaxy appearance controls also cover sphere rotation speed, fixed interface text size, and lens highlight and flare intensity; the sphere's own text-size control remains separate.

## Dictionary and preferences

- **Add terms without erasing ordinary meanings.** The bundled `terms.sqlite` contains **370 distinct entries** built from `scripts/terms.csv`. When both dictionaries match, technical Chinese definitions and optional English explanations appear in a separate glossary section beside ECDICT senses; terms absent from ECDICT can appear on their own. Community additions can be made to the CSV source.
- **See root meanings clearly.** Root decomposition groups word parts as badges and places each part's meaning on its own line. The root-analysis toggle remains available in Settings.
- **Hear both accents automatically if requested.** The new **Speak after lookup** option reads the British pronunciation followed by the American one on opening a dictionary card. It is opt-in; separate speech controls remain available.
- **Choose the display language.** English and Simplified Chinese resources are bundled. The app follows macOS by default and offers an override in **Settings → General → Language**; this changes interface text, not the English–Chinese dictionary data.
- **Return to the current workspace.** By default, reopening the workspace places it on the active desktop and current screen rather than taking you back to its old location; the setting can be disabled. Source-app icons replace generic indicators in relevant views, and the glass-shell transition is less stark in light mode.

## Compatibility and source release

- Requires **macOS 26+**. The glossary ships with the app and does not migrate or replace user library entries. `build.sh` now takes the app's version from the nearest Git tag, assembles dependency resources, and verifies its signature after signing.
- This tag includes CI and a tag-driven release workflow designed to attach ZIP and DMG assets. A tag is not itself a downloadable app: check [GitHub Releases](https://github.com/UNLINEARITY/Voca/releases) for actual assets, or run `./build.sh` to build from source. CI artifacts use ad-hoc signing and are not notarized.
- **Known limitation of this tag:** on English-language macOS hosts, explicitly selecting Simplified Chinese can leave some programmatically localized strings in English. Source changes after the tag correct the language override; the `3.0.0` tag itself does not include that fix.
