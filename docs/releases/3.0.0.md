# Voca 3.0.0 Release Notes

## Overview

Voca 3.0.0 is the first public release: a local-first, fully offline macOS menu bar app that turns every piece of text you select, copy, or look up into a personal library you can wander through.

- **Save as you read**: select text anywhere, press `⌥⇧S`, and it is saved silently with a quiet toast — no interruption.
- **Clipboard history**: copied text and images are archived automatically; promote anything to the library with one click; concealed pasteboard items are skipped.
- **Lookup and translate**: `⌥⇧D` or the Services menu opens a cursor-side dictionary card — a 610k-entry offline English–Chinese dictionary with roots, word families, and synonyms, falling back to on-device translation.
- **Timeline wall**: the fullscreen galaxy lays your whole library out by real save time on a wall you drag, scroll, and pinch across, anchored by a dial-style date ruler.
- **Word galaxy**: the library and clipboard render as a 3D glass sphere with live desktop refraction and per-entry timelines.
- **Local only**: everything lives in a single SQLite file — no account, no cloud, no telemetry.

## Major features

### Selection saving and clipboard history

- Global shortcut saves selected text (`⌥⇧S`, customizable) with an accessibility-first capture path and a copy-and-restore fallback; secure text fields are always skipped.
- Clipboard history keeps text and images; concealed entries never land; history stays separate from the library until you tap ➕.
- Saving identical text merges automatically: count +1, moved to top, timeline event recorded.
- Optional experimental three-finger swipe-to-save gesture (off by default).

### Dictionary, glossary, and translation

- Embedded ECDICT English–Chinese dictionary (610k entries: phonetics, bilingual senses, exam tags, frequency, Collins stars), fully offline.
- **Embodied-AI glossary**: 373 AI/robotics/embodied-intelligence terms (grounding, affordance, sim2real, VLA…) shown as a dedicated section alongside the original senses, extensible by the community via `scripts/terms.csv`.
- Dictionary misses fall back to Apple's on-device translation (English↔Chinese); translations can be saved into the library as notes.
- British and American offline speech; enable "Speak after lookup" to play both automatically.
- Double-click any word or phrase in lists or the galaxy to look it up.

### Timeline wall and word galaxy

- Timeline: entries positioned by real save time (oldest left); idle gaps capped; a readability-first layout widens the axis instead of shrinking text.
- Interact by direct drag or two-finger pan; zoom the time axis with the vertical wheel or pinch (pointer-anchored); double-click empty space to reset; click an entry for details and actions.
- A dial-style ruler (baseline, minor and major ticks, glass date chips) adapts its granularity to the zoom; the frosted background strength is adjustable.
- Sphere: SceneKit word sphere with live desktop refraction (native fallback without screen permission); selecting an entry reveals source app, save count, and a paginated timeline.
- The menu bar "Galaxy" menu gathers timeline/library/clipboard, galaxy settings, and exit; usage hints live under Help → Voca Help.

### Workspace and personalization

- Resizable workspace with Settings, full-text-search Library, and Clipboard tabs; `⌥⇥V` opens it on your current desktop and screen by default (configurable).
- Adjustable list and popup typography, popup width and reading height, galaxy UI text size, and timeline background strength.
- The interface follows your system language (Simplified Chinese / English) and can be pinned in Settings.
- Safe database management: in-place backup (VACUUM INTO), Reveal in Finder, Markdown export.

## Privacy and data

- Everything runs offline: the dictionary is embedded, translation and speech are system capabilities, and data lives in `~/Library/Application Support/Voca/voca.sqlite`.
- Screen content is processed in memory only while the galaxy is open and is never saved.
- Deletes and clears always confirm their exact scope.

## Requirements and getting it

- macOS 26 or later, Apple Silicon.
- Download `Voca-3.0.0-macOS.zip` from GitHub Releases, unzip, and drag to Applications; grant Accessibility on first launch.
- Building from source: `swift build` / `./build.sh` (versions are stamped from git tags).
