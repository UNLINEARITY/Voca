# Voca 1.0.0 发行说明

## 概览

这个源码标签确立了 Voca 的最初工作流：在其他 macOS 应用中选中文字，静默收入本机词库，再通过可搜索列表或全屏词语星图回看。剪贴板历史是独立收藏面，不会自动并入词库。

## 划词与词库

- **无需切换应用即可保存。** 按 **⌥⇧S**（可从菜单栏重新录制）。Voca 优先读取辅助功能选区；不可用时模拟复制，只在剪贴板确实变化后读取文字，再恢复原有内容。安全输入框不参与捕获；保存后仅在右下角显示提示。
- **同一段文字保留多次保存记录。** 再次保存相同文字会合并为一个词条，增加次数、更新最近保存时间，并在时间线加入一条事件。列表支持全文搜索、编辑原文及多行备注、展开长文、复制回剪贴板和查看词条时间线。
- **尽可能保留来源。** Safari 和受支持的 Chromium 浏览器可通过自动化权限读取当前标签页地址；拒绝授权或无法取得地址时仍会保存文字。已记录的来源链接可从词条打开。
- **导出与删除有明确边界。** Markdown 按最近保存时间导出词条，备注写作引用块，词条之间留空行，不包含 URL。删除单条或清空词库会确认操作范围。

## 剪贴板与星图

- **剪贴板历史与词库分开。** 复制的文本单独存入 SQLite，只有点击 **+** 才收入词库；图片与文件仅在本次会话显示。标记为保密的内容和 Voca 模拟复制的内容会跳过，短时间内重复写入的相同文本也会被抑制。
- **在词球上探索。** 按 **⌥⇧V** 或从菜单栏进入全屏星图，可切换词库文字、剪贴板文字以及折射／检索视图；旋转球体、选择文字排布、调整外观，或查看词条详情与分页保存时间线。
- **屏幕采集并非星图的前提。** 实时桌面折射需要屏幕录制权限，画面只在内存中处理；采集不可用时，原生词球仍可操作。

## 兼容性与数据

- 需要 **macOS 26 或更高版本**；在此标签运行 `./build.sh` 可生成 `build/Voca.app`。划词需要辅助功能权限，浏览器地址与桌面折射分别按需请求权限；无需云端账户。
- 词库、保存事件和剪贴板文本历史位于 `~/Library/Application Support/Voca/voca.sqlite`。此版本不持久保存图片和复制的文件。若直接复制 SQLite 文件备份，请先退出 Voca。
- 这个历史标签的 `build.sh` 即使从 `1.0.0` 源码构建，应用包内版本号仍写为 `0.1.0`；源码标签本身不提供安装包。
