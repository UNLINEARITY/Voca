# Voca 3.2.0 发行说明

## 概览

相较于 3.1.0，Voca 3.2.0 重建了时间线的布局与稳定性：缩放范围扩展至 0.125×–8×，日期标尺随可见时间范围自适应，任何缩放下词条都不横向重叠、不换行、不丢失。星图透镜的调参范围扩大以获得更通透的玻璃观感，时间线档新增 ⌘+滚轮缩放文字大小。

## 时间线：范围、标尺与稳定性

- **缩小即可总览全部历史。** 最小缩放降至 0.125×，横跨数屏的时间线也能收进一屏；放大上限仍为 8×。双击空白复位至 1×。
- **标尺随缩放联动。** 日期刻度按可见时间范围自适应——近处显示小时与日期，远处显示月份、季度与年份，不再固定于数据整体跨度；刻度与词条共用同一时间映射，任何缩放下保持对齐。
- **自适应排布且不丢词。** 只要任一行可以容纳，词条就按真实时间位置放置，密集时段仅展开必要的最小幅度。行分配在任何缩放下均保持 1× 基准不变，内容宽度由二分法精确求解，缩小时在同行内连续顺延——任何缩放下都不换行、不横向重叠、不丢失词条。
- **缩放更平滑。** 加宽计算统一在 1× 下完成，位置严格随缩放线性变化，消除了此前缩放过程中的闪烁；平移边界随每次缩放同步更新。

## 星图细节

- **通透观感触手可及。** 透镜滑杆范围扩大：色散分布下限延伸至 0.5，内圈起始最高可达 0.995（暗环可收窄为细线），菲涅尔蓝上限提高一倍——无需改码即可调出更通透的组合。
- **时间线内缩放文字。** 时间线档新增 ⌘+滚轮调整文字大小（普通滚轮保留给时间轴缩放）；球体档保持原有的滚轮缩放行为。
