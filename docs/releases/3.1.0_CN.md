# Voca 3.1.0 发行说明

## 概览

相较于 3.0.0，Voca 3.1.0 补全了整个界面的双语覆盖——包括 macOS 菜单——解决了 3.0.0 已记录的语言覆盖限制，新增隐藏 Dock 图标也可用的星图设置快捷键（可自定义），让「Voca 帮助」成为始终反映当前绑定的完整快捷键清单，并支持在词库页直接录入词条——高频保存的词在星图球面上也更醒目。

## 完全双语的界面

- **显式语言选择在任何系统上都生效。** 选择英文或简体中文后，所有以程序方式本地化的文字都固定从对应语言的字符串表读取，不受 macOS 系统语言影响。这解决了 `3.0.0` 标签的已知限制——在英文 macOS 环境下选择简体中文后部分文字仍显示英文。
- **Voca 自有菜单实时跟随语言设置。** Galaxy 菜单及其条目、帮助菜单项和帮助窗口在更改语言偏好后立即切换。
- **macOS 标准菜单同样跟随语言选择。** 应用、编辑、显示、窗口和帮助菜单通过 macOS 的应用级语言偏好读取所选语言；由于 macOS 在启动时构建标准菜单，它们在下次打开 Voca 时生效，需要时设置页会给出提示。苹果菜单仍跟随系统语言；若你在系统设置中为 Voca 单独设过语言，切回「跟随系统」时会原样恢复。
- **最后的硬编码文字完成本地化。** 此前未翻译的文字（如保存失败提示）现在也跟随语言选择。

## 星图设置快捷键

- **不依赖菜单栏即可开关实时调参。** 星图窗口聚焦时按 **⌥⇧G** 即可显示或隐藏「星图设置」面板，调参不再依赖应用菜单或可见的 Dock 图标。
- **可自定义且不与其他应用冲突。** 快捷键可在设置页或菜单栏面板中更改；按键仅在本地处理，不会拦截其他应用的按键。

## 作为快捷键参考的帮助页

- **全部快捷键、始终最新。** 「Voca 帮助」列出完整的快捷键集合：四个可自定义快捷键显示你实际绑定的组合键——清除后明确显示「未设置」——固定按键按场景说明，例如未编辑文字时的标签与星图档位循环、进出星图、**⌘N** 直接添加词条、编辑词库球面选中的词条，以及 Esc 先关闭查词浮窗再退出星图。
- **帮助页自动保持最新。** 已打开的帮助窗口在你改录快捷键后立即刷新，内容也跟随语言选择。

## 直接录入与按计数放大的词球

- **不经过划词也能录入词条。** 词库标签新增工具栏按钮、**⌘N** 快捷键和空状态页的添加入口，面板复用熟悉的内容+备注编辑器。手动添加与划词保存同一合并语义：相同文本计数 +1、置顶、记录来源为 Voca 的时间线事件，备注留空不覆盖已有备注；新词条立即出现在词库星图中。
- **高频词在球面上更醒目。** 词库星图的球面文字随保存计数变大（每次 +2.5 pt、封顶 +20，以获得更强的表现力），剪贴板条目保持基准字号，文字大小滑杆继续整体缩放。

- 需要 **macOS 26 或更高版本**。本版本不涉及数据迁移。`build.sh` 从最近的 Git 标签读取版本号，因此此标签下构建的应用包版本为 **3.1.0**。
- 标签本身不等于可下载应用：请在 [GitHub 发行页面](https://github.com/UNLINEARITY/Voca/releases)查看实际附件，或运行 `./build.sh` 自行构建。持续集成产物采用临时签名，未经 Apple 公证。
