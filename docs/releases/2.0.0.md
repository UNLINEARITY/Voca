# Voca 2.0.0 Release Notes

## Overview

Compared with 1.0.0, Voca 2.0.0 adds lookup and translation directly to the selection workflow. A bundled English–Chinese dictionary, a cursor-side popup, and a unified workspace make it possible to study a word without first saving it. Clipboard images also survive restarts for the first time.

## Dictionary, speech, and translation

- **Look up a selection in place.** Press **⌥⇧D** or use the macOS **Look Up with Voca** text service. The popup appears near the cursor; the library editor also has dictionary access, and double-clicking a word or phrase in the library or galaxy opens lookup without editing the entry.
- **Read without a network dictionary.** The bundled, read-only ECDICT-derived database contains **609,603 entries** at this tag. Available fields include phonetics and English/Chinese definitions; word forms can point back to a lemma. Optional learning sections show roots, word families, related phrases, and thesaurus synonyms when the data exists. Intelligent root decomposition can be turned off.
- **Choose an accent.** Separate British and American buttons read the word aloud with macOS speech voices, without requiring online audio.
- **Translate a miss.** If lookup does not find a dictionary entry, the popup offers Apple's on-device English↔Chinese translation. Save the original selection to the library and, if desired, keep the translation as its note. macOS may need to download the relevant translation language pack.

## Workspace, clipboard, and save feedback

- **One workspace instead of separate record and clipboard windows.** Settings, searchable Library, and Clipboard are tabs in a resizable window; **⌥⇧V** opens it. Keyboard navigation connects workspace tabs and galaxy modes. The settings tab collects shortcut recorders, list and popup typography, clipboard monitoring, and other controls.
- **Tune lookup where it is used.** Popup width ranges from **360–560 pt** and its reading area from **120–480 pt**; a dictionary-card preview in Settings reflects width and font changes.
- **Keep image copies across launches.** Supported PNG, TIFF, JPEG, HEIC, and GIF clipboard representations are stored with their original encoded bytes in the local database. Text and images share a chronological history view; previews are generated when needed. Copied files remain session-only. Clearing clipboard history includes unloaded records and images but does not clear the saved-text library.
- **Keep intentional copies safe.** The selection-copy fallback now leaves a newer user copy in place rather than restoring over it. A save confirmation gains a small animation; other feedback remains quiet.
- **Back up while the app is open.** Settings can create a compact SQLite snapshot with `VACUUM INTO`, alongside database information and library-management controls.

## Optional trackpad input and compatibility

- An optional **three-finger downward swipe** on an Apple trackpad saves selected text. It is disabled by default, uses an undocumented macOS interface, and may conflict with App Exposé; **⌥⇧S** remains available.
- Requires **macOS 26+**. The new dictionary and clipboard-image table are bundled or migrated without replacing existing saved text. This historical tag's `build.sh` still stamps the app as `0.1.0`; the tag itself does not provide an installer.
