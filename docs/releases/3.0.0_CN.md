# Voca 3.0.0 发行说明

## 概览

相较于 2.0.0，Voca 3.0.0 将星图原先的检索呈现改为静态时间线词墙，在查词中加入内嵌专业术语库，并重新组织工作区与星图的导航。界面还加入英文和简体中文资源，以及可自行指定的显示语言。

## 按时间浏览的检索视图

- **按最近保存时间定位词条。** 全屏检索视图将词库文字按从旧到新的顺序分行排布。长期未保存的间隔在布局中最多按 **14 天**计，标签重叠时换行而不缩小文字；行数超过屏幕容量时，时间轴会向屏幕外延伸，保持字号可读。
- **一眼看到保存次数与日期。** 保存次数越多，词条字号越大，额外增幅最高 **10 pt**。底部日期标尺提供带标签的主刻度和较短的次级刻度，日期粒度随整体时间跨度调整。
- **平移、缩放与复位。** 拖动或双指左右滑动浏览；使用滚轮或捏合以指针为中心缩放，最高 **8 倍**。单击词条查看详情与操作，双击词条打开查词浮窗，双击空白处复位视图。
- **词球仍供词库与剪贴板使用。** 菜单栏可直接打开时间线、词库或剪贴板星图，也可进入星图设置；操作说明移至**帮助 → Voca 帮助**。
- **调整背景而不遮挡词墙。** 时间线磨砂背景浓度可在 **30%–100%** 间调节（默认 **70%**）。星图外观选项还包括球体自转速度、固定的界面字号、透镜高光和光斑强度；球面文字字号仍单独控制。

## 词典与偏好设置

- **专业术语不覆盖普通词义。** 内嵌 `terms.sqlite` 从 `scripts/terms.csv` 生成，包含 **370 条不同词条**。同时命中时，术语的中文释义和可选英文说明在 ECDICT 释义旁单独展示；主词典未收录的术语也可以独立显示。社区可通过 CSV 源文件补充术语。
- **逐项呈现词根含义。** 词根拆解将单词组成部分排成徽章，每个部分的含义单独成行；智能词根拆解开关仍可在设置中使用。
- **按需自动朗读双口音。** 开启**查词后自动发音**后，打开词典卡会先读英音、再读美音。该功能由用户自行开启，原有的单独朗读按钮保留。
- **选择界面语言。** 应用内嵌英文与简体中文资源，默认跟随 macOS，也可在**设置 → 通用 → 语言**中指定。此设置只影响界面文字，不改变英汉词典的数据。
- **工作区跟随当前桌面。** 重新打开工作区时，默认出现在当前桌面与屏幕，而非跳回旧位置；可在设置中关闭。相关界面使用来源应用图标代替通用符号，浅色外观下的玻璃过渡也更柔和。

## 兼容性与源码发布

- 需要 **macOS 26 或更高版本**。术语库随应用提供，不迁移或替换用户词库。`build.sh` 开始从最近的 Git 标签读取版本号，在组装依赖资源后签名并验证应用包。
- 此标签包含持续集成及按标签触发的发布流程，用于生成 ZIP 和 DMG。标签本身不等于可下载应用：请在 [GitHub 发行页面](https://github.com/UNLINEARITY/Voca/releases)查看实际附件，或运行 `./build.sh` 自行构建。持续集成产物采用临时签名，未经 Apple 公证。
- **此标签的已知限制：**在英文 macOS 环境下，显式选择简体中文后，部分以程序方式本地化的文字仍可能显示英文。标签之后的源码已修正此问题，但 `3.0.0` 标签本身不包含修复。
