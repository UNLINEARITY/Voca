# Voca 3.0.0 发行说明

## 概述

Voca 3.0.0 是首个公开发布版本：一款本地优先、完全离线的 macOS 菜单栏应用，把你划过、复制过、查过的每一段文字变成一座可以漫游的个人词库。

- **划词即存**：在任意应用里选中文字，按 `⌥⇧S` 静默保存，右下角轻提示确认，不打断你正在做的事。
- **剪贴板历史**：复制的文字与图片自动留档，点一下收入词库；密码管理器标记的保密内容自动跳过。
- **查词与翻译**：`⌥⇧D` 或右键服务在光标旁弹出词典卡——内嵌 61 万词条英汉词典、词根拆解、词形家族、同义词，未命中自动走系统离线翻译（英↔中）。
- **时间线词墙**：全屏星图里把整个词库按真实保存时间铺成一面词墙，拖动、滚轮、捏合随意浏览；底部是表盘式日期标尺。
- **词语星图**：词库与剪贴板以三维玻璃球呈现，旋转、选中、回溯每条词条的保存时间线。
- **完全本地**：所有数据存放在单个 SQLite 文件，无账户、无云端、无遥测。

## 主要特性

### 划词保存与剪贴板历史

- 全局快捷键保存选中文字（`⌥⇧S`，可自定义），辅助功能不可用时自动降级为复制并恢复原剪贴板；密码框安全跳过。
- 剪贴板历史记录文本与图片，敏感内容（`org.nspasteboard.ConcealedType`）不入档；历史与词库相互独立，点 ➕ 才入库。
- 重复保存同文自动合并：计数 +1、置顶、记录时间线事件。
- 可选实验性三指下滑手势保存（默认关闭）。

### 词典、术语与翻译

- 内嵌 ECDICT 英汉词典（61 万词条：音标、中英释义、考试标签、词频、柯林斯星级），完全离线。
- **具身智能术语库**：373 条 AI／机器人／具身智能术语（grounding、affordance、sim2real、VLA……）以独立「术语」区块与原释义并存展示，社区可经 `scripts/terms.csv` 共建。
- 词典未命中自动调用 Apple 设备端翻译（英↔中），译文可一键入库作为备注。
- 英音／美音离线发音；「设置 → 词典 → 查词后自动发音」开启后自动连播（先英后美）。
- 词库列表与星图中双击任意单词/短语即可查词。

### 时间线词墙与词语星图

- 时间线档：词条按真实保存时间横向定位（旧→新），空闲期自动封顶；可读优先布局，放不下即拉宽时间轴供滑动浏览。
- 交互：直接拖动或双指左右滑动平移；垂直滚轮或捏合缩放时间轴（指针为锚）；双击空白复位；单击词条浮出详情与操作栏。
- 底部表盘式标尺：基线＋次级刻度＋主刻度＋玻璃胶囊日期，粒度随缩放自适应；磨砂背景浓度可在星图设置中调节。
- 球体档：SceneKit 词球＋桌面实时折射透镜（无屏幕录制权限时保留原生后备）；选中词条展示来源应用、保存次数与时间线分页。
- 菜单栏「星图」菜单集中打开时间线/词库/剪贴板、星图设置与退出；操作提示收纳在「帮助 → Voca 帮助」。

### 工作区与个性化

- 可调大小的工作区窗口：设置、词库（全文搜索）、剪贴板三标签，`⌥⇥V` 打开并默认出现在当前桌面与屏幕（可配置）。
- 列表字号、浮窗字号/宽度/阅读区高度、星图界面字号、时间线背景浓度均可调。
- 界面跟随系统语言：简体中文／英文，亦可在设置中手动指定。
- 安全数据库管理：运行中安全备份（VACUUM INTO）、Finder 定位、Markdown 导出。

## 隐私与数据

- 一切功能离线运行：词典内嵌、翻译与发音为系统能力、数据本地 SQLite（`~/Library/Application Support/Voca/voca.sqlite`）。
- 屏幕内容仅在星图打开时于内存中处理用于折射效果，永不保存。
- 删除与清空操作均需确认其作用范围。

## 系统要求与获取

- macOS 26 或更高版本，Apple Silicon。
- 从 GitHub Releases 下载 `Voca-3.0.0-macOS.zip`，解压拖入「应用程序」；首次使用需在系统设置授予辅助功能权限。
- 源码构建：`swift build`／`./build.sh`（版本号自动取自 git tag）。
