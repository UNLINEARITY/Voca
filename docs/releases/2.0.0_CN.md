# Voca 2.0.0 发行说明

## 概览

相较于 1.0.0，Voca 2.0.0 把查词与翻译接入划词流程：内嵌英汉词典、光标旁浮窗和统一工作区，让你不必先收藏就能查阅文字。复制的图片也首次可以跨重启保留。

## 词典、发音与翻译

- **就地查阅选区。** 按 **⌥⇧D** 或使用 macOS 文本服务「用 Voca 查词」，浮窗会出现在光标附近。词条编辑界面也可查词；在词库或星图中双击单词、短语，可不修改词条直接打开查词浮窗。
- **无需联网词典。** 此标签内嵌的只读 ECDICT 衍生数据库包含 **609,603 个词条**，按已有数据提供音标、中英释义，并可从词形变体找到原形。学习区按数据情况展示词根、词形家族、相关短语和同义词；智能词根拆解可关闭。
- **分别选择口音。** 英音与美音各有朗读按钮，使用 macOS 系统语音，无需在线获取发音音频。
- **词典未命中时翻译。** 浮窗提供 Apple 设备端英↔中翻译；可将原文收入词库，并按需把译文存为备注。相关翻译语言包可能需要由 macOS 先行下载。

## 工作区、剪贴板与保存反馈

- **记录与剪贴板共用工作区。** 可调整大小的窗口将设置、可搜索的词库与剪贴板合为三个标签；按 **⌥⇧V** 打开。键盘导航连接工作区标签与星图档位；设置页汇集快捷键录制、列表和浮窗字号、剪贴板监听等选项。
- **边调边看查词卡。** 浮窗宽度可设为 **360–560 pt**，阅读区高度可设为 **120–480 pt**；设置页的词典卡预览会随宽度和字号调整。
- **图片复制记录可跨重启保留。** 支持把 PNG、TIFF、JPEG、HEIC 和 GIF 的原始编码数据存入本地数据库。文本与图片在同一时间顺序的历史页中显示，按需生成图片预览；复制的文件仍仅本次会话可见。清空历史会包含未载入记录与图片，但不影响词库。
- **不覆盖后来的手动复制。** 划词复制降级路径若检测到用户又复制了新内容，就不会以旧剪贴板状态覆盖它。保存确认增加轻量动画，其他提示仍保持安静。
- **运行中安全备份。** 设置页可通过 `VACUUM INTO` 生成紧凑的 SQLite 快照，并查看数据库信息及管理词库。

## 可选触控板操作与兼容性

- Apple 触控板可选启用**三指下滑保存**。默认关闭，依赖 macOS 未公开接口，可能与 App Exposé 冲突；**⌥⇧S** 始终可用。
- 需要 **macOS 26 或更高版本**。新增词典及剪贴板图片表不会替换已有词库数据。这个历史标签的 `build.sh` 仍将应用包版本号写为 `0.1.0`；源码标签本身不提供安装包。
