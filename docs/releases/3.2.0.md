# Voca 3.2.0 Release Notes

## Overview

Compared with 3.1.0, Voca 3.2.0 rebuilds the timeline around a stable, adaptive layout: the zoom range now spans 0.125× to 8×, the date ruler follows the visible time window, and words never overlap, change rows, or disappear at any zoom level. The galaxy lens gains wider tuning ranges for clearer glass, and the timeline mode adds ⌘+scroll text-size zooming.

## Timeline: range, ruler, and stability

- **Zoom out to the whole history.** The minimum zoom drops to 0.125×, so even a timeline that spans several screens fits one view; zooming in still reaches 8×. Double-clicking empty space resets to 1×.
- **A ruler that follows the zoom.** Date ticks adapt to the visible time window — hours and days up close, months, quarters, and years when zoomed out — instead of the whole data span, and they share the entry layout's time mapping so they stay aligned at every zoom level.
- **Adaptive packing without losses.** Each word sits at its true time whenever any row can hold it; dense clusters expand only as far as needed. Row assignment stays fixed at the 1× baseline across all zoom levels, the content width is solved exactly by binary search, and zooming out shifts words within their own rows continuously — no row changes, overlaps, or lost entries at any scale.
- **Smoother zooming.** Widening is computed once at 1× and positions scale strictly linearly, removing the flicker that previously appeared while zooming; pan bounds track every zoom step.

## Galaxy polish

- **Clearer glass within reach.** The lens sliders cover wider ranges: dispersion spread extends down to 0.5, the inner rim can narrow to a hairline at 0.995, and the Fresnel blue ceiling doubles — clearer configurations are now reachable without code changes.
- **Text-size zoom in the timeline.** ⌘+scroll adjusts text size in the timeline mode, where plain scrolling controls the time axis; the sphere modes keep their existing scroll-to-zoom behavior.

## Compatibility and source release

- Requires **macOS 26 or later** on Apple Silicon. No data migration is involved. `build.sh` takes the version from the nearest Git tag, so bundles built at this tag report **3.2.0**.
- A tag is not itself a downloadable app: check [GitHub Releases](https://github.com/UNLINEARITY/Voca/releases) for actual assets, or run `./build.sh` to build from source. CI artifacts use ad-hoc signing and are not notarized.
