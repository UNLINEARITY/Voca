# Voca 3.1.0 Release Notes

## Overview

Compared with 3.0.0, Voca 3.1.0 completes bilingual coverage across the whole interface — including the macOS menus — resolves the language-override limitation documented for 3.0.0, adds a customizable shortcut for Galaxy Settings that works with the Dock icon hidden, turns Voca Help into a complete shortcut reference that always reflects your current bindings, and lets you add library entries directly, with frequently saved words standing larger on the galaxy sphere.

## A fully bilingual interface

- **Explicit language choices now work on any system.** Selecting English or Simplified Chinese resolves every programmatically localized string from its own language table, regardless of the macOS system language. This resolves the known limitation of the `3.0.0` tag, where some strings stayed English on English-language hosts after choosing Simplified Chinese.
- **Voca's own menus follow the language setting live.** The Galaxy menu, its items, the help menu entry, and the help window switch immediately when the language preference changes.
- **Standard macOS menus follow the language selection too.** The app, Edit, View, Window, and Help menus apply the in-app language through the per-app macOS language preference. They update the next time Voca opens — with a note in Settings when that applies — because macOS builds standard menus at launch. The Apple menu keeps following the system language, and any per-app language you set in System Settings is preserved and restored when you switch back to Follow System.
- **The last hardcoded strings are localized.** Remaining untranslated text, such as the save-failure message, now follows the language selection.

## Galaxy Settings shortcut

- **Toggle live tuning without the menu bar.** Pressing **⌥⇧G** while the galaxy window is focused shows or hides the Galaxy Settings panel, so tuning no longer depends on the application menu or a visible Dock icon.
- **Customizable and conflict-free.** The shortcut can be changed in Settings or the menu bar panel; the binding is handled locally and never intercepts keys in other applications.

## Help as a shortcut reference

- **Every shortcut, always current.** Voca Help lists the complete shortcut set: the four customizable shortcuts show your actual bindings — including an explicit "Not set" when cleared — and fixed keys are documented by context, such as tab and galaxy-mode cycling outside text editing, entering and leaving the galaxy, adding a library entry with **⌘N**, editing the selected Library sphere entry, and Esc dismissing the lookup popup before exiting.
- **Help keeps itself up to date.** An open help window refreshes immediately after you record a different shortcut, and its content follows the language selection.

## Direct input and count-sized galaxy words

- **Add entries without capturing first.** The library tab gains a toolbar button, an **⌘N** shortcut, and an add action on the empty-state page. The sheet reuses the familiar content-and-note editor, and manual additions follow the same merge semantics as saving a selection: identical text increments its count, moves the entry to the top, records a timeline event attributed to Voca, and an empty note leaves the existing note untouched. New entries appear in the library galaxy immediately.
- **Frequently saved words stand out on the sphere.** Library words on the galaxy sphere now grow with their save count — +2.5 pt per save, capped at +20 for a stronger presence — while clipboard entries keep the base size and the text-size slider keeps scaling everything.

## Documentation

- The bilingual READMEs now present Voca as a product — installation, privacy, and each workflow — without source-level or release-process detail, and the release notes for 1.0.0 through 3.0.0 were completed against the actual tags.

## Compatibility and source release

- Requires **macOS 26+**. No data migration is involved. `build.sh` takes the version from the nearest Git tag, so bundles built at this tag report **3.1.0**.
- A tag is not itself a downloadable app: check [GitHub Releases](https://github.com/UNLINEARITY/Voca/releases) for actual assets, or run `./build.sh` to build from source. CI artifacts use ad-hoc signing and are not notarized.
