# Voca 1.0.0 Release Notes

## Overview

This source tag establishes Voca's original workflow: capture selected text from another macOS app, save it silently to a local library, and return to it through a searchable list or fullscreen word galaxy. Clipboard history is a separate collection rather than an automatic extension of the library.

## Capture and library

- **Save without switching apps.** Press **⌥⇧S** (recordable from the menu bar). Voca reads the Accessibility selection when available; otherwise it simulates a copy, accepts text only after the pasteboard changes, and restores the previous contents. Secure text fields are excluded. A bottom-right toast confirms a save.
- **Keep the history of a text, not just its latest copy.** Saving identical text merges into one library entry, increments its count, updates recency, and records a separate save event. The list supports full-text search, editing text and multiline notes, expansion of long entries, copy-back, and an entry timeline.
- **Carry source context when possible.** For Safari and supported Chromium browsers, Voca can ask for the active tab URL through Automation; refusing access or failing to find a URL does not block saving. Source links can be opened from saved items.
- **Export and delete deliberately.** Markdown export puts entries in recency order, with notes as blockquotes and blank lines between entries; URLs are not exported. Individual deletion and clearing the library require scope-specific confirmation.

## Clipboard and galaxy

- **Clipboard history is separate from the library.** Text copies persist in a separate SQLite table and are promoted to the library only by clicking **+**. Copied images and files appear during the current session only. Concealed pasteboard contents and Voca's simulated copies are skipped; rapid duplicate writes of the same text are suppressed.
- **Explore a word sphere.** Open the fullscreen galaxy with **⌥⇧V** or the menu bar. Switch between library text, clipboard text, and the refraction/search view; rotate the sphere, choose a text layout, adjust its presentation, and inspect an entry's details or paged save timeline.
- **Screen capture is optional.** Live desktop refraction uses Screen Recording permission and processes frames in memory. The native sphere remains interactive if capture is unavailable.

## Compatibility and data

- **macOS 26+**; build this tag with `./build.sh` to create `build/Voca.app`. Accessibility is needed for selection capture; browser URLs and desktop refraction ask for separate permissions. No cloud account is required.
- Saved text, save events, and clipboard text history use `~/Library/Application Support/Voca/voca.sqlite`. Images and copied files are not persisted in this version. Back up the database with Voca closed if copying the SQLite file manually.
- This historical tag's `build.sh` writes `0.1.0` into the app bundle version even when building the `1.0.0` source tag. The tag itself does not provide an installer.
