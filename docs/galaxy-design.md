# Galaxy implementation snapshot

This document describes the current galaxy implementation for orientation and regression testing. It is not an immutable product specification. A new user request may change the structure, appearance, interaction, or parameter values while retaining required privacy, fallback, and runtime-safety guarantees.

## Current composition

`GalaxyView.sphere(diameter:)` currently layers the following elements from outside to inside:

1. A Metal refraction lens spanning 1.25 times the sphere diameter by default (configurable). Its outer annulus provides dispersion and refraction when screen capture supplies usable frames.
2. A native clear glass ring at the same scale, providing a visible transparent fallback when the Metal path has no content.
3. A frosted core at the sphere diameter, built from material, gradients, highlights, and a rim so the center remains readable without capture permission.
4. A SceneKit word sphere with curved labels, a uniform 25-point logical font baseline at 1× regardless of save count, persisted slider-controlled text scale, automatic rotation, and drag or precise two-finger-scroll inertia. The tuning panel offers the original Fibonacci scattering (default) or latitude bands for both library and clipboard items. Latitude bands receive entries in symmetric pairs, with band populations proportional to circumference and neighboring bands staggered; this changes placement, not the font size or maximum item count.

The tuning panel exposes persisted controls for dispersion, chroma, refraction, rim and fresnel treatment, text scale, sphere/ring scale, core darkening, rotation direction, and distribution. Switching distribution moves the existing text nodes briefly into their new positions without blanking the sphere or dropping the current selection; reset returns to Fibonacci scattering. Direct rotation (labels follow pointer/finger motion) is the default; the reverse option flips both drag and precise-scroll rotation, and reset restores the default. Pinching or scrolling a phase-less wheel on the sphere adjusts the same text scale; phase-bearing precise scrolls rotate the sphere except while the timeline is open, when scrolling pages through events. Defaults represent the currently accepted preset, not permanent constants.

The top-bar source selector switches between the timeline, the saved library, and the clipboard's text history without combining their storage. The macOS menu bar carries a single Galaxy menu with open-search/library/clipboard commands (each switching the source and opening the galaxy), the tuning toggle, and exit; former in-window hints moved to the Help menu's Voca Help window; keyboard routes unchanged. The timeline source fills the whole window with the wall over a frosted material background (strength configurable in the galaxy tuning panel) and no bottom bar: entries are positioned horizontally by their real save time (older left, newer right, idle gaps capped at 14 days), vertically stacked into collision-free rows and centered as a block, with save frequency determining text size, chip text truncated beyond a maximum width, and date ticks along the bottom whose granularity adapts to the zoom. Readability comes first: the axis widens beyond the screen instead of shrinking text, with two-finger horizontal scrolling and edge-aware panning; the whole span auto-fits only when sparse. The vertical scroll wheel, two-finger vertical scrolling, and pinch all zoom the time axis around the pointer, and double-clicking empty space resets to the centered midpoint view. A single click shows the shared selection detail and action bar at the bottom, and a double click opens the lookup popup. The timeline can be panned by direct dragging or two-finger horizontal scrolling. The tuning panel docks beside and shrinks the canvas when open. The library and clipboard sources keep the sphere with their selection orbit. The last galaxy source is restored across launches. Clipboard image and file history remains in the clipboard tab of the unified list window; the galaxy only consumes text entries. Selecting clipboard text shows its full scrollable content, app and web source, copy time and length, with copy and add-to-library actions. Saved entries keep their symmetric source/save-count labels. When sphere text is truncated, the existing scrollable note card shows the original full text first, then an optional note after a blank line; untruncated entries retain their note-only presentation. Their timeline presents up to six dated events per page on paired arcs, with wheel/trackpad paging and on-screen page controls. The selected word retains the regular texture and color, enlarges slightly, and lifts outward from the sphere while other words recede. In the normal selection action bar, deletion requires a scope-specific confirmation: deleting a library entry removes its timeline events, while removing clipboard history leaves any saved-library copy intact. Timeline paging does not offer deletion.

The galaxy and unified list are two keyboard layers. Shift-Option-Up moves from the galaxy to the corresponding list tab (refraction maps to library); Shift-Option-Down returns to that tab's galaxy. Shift-Option-Left/Right switches list tabs or follows the galaxy's refraction–library–clipboard order. The galaxy also retains its Shift-Command-Left/Right alias. Text editing and modal dialogs take precedence over these routes. The global workspace shortcut reopens the last active layer and list tab, while the menu command opens the galaxy directly. By default the workspace reappears on the desktop and screen you are currently using (windows adopt move-to-active-space presentation and the panel recenters on the mouse screen across monitors); the Settings toggle turns this off to restore remembered-position behavior. Vertical transitions animate a temporary non-interactive glass shell between sphere and window while content fades; Reduce Motion uses only a brief fade.

## Required regression properties

When changing the galaxy, verify that:

- It remains visible and usable when ScreenCaptureKit returns no displays or frames.
- Closing the window does not remove an active event monitor from inside its callback.
- The fullscreen hosting arrangement retains the intended window frame.
- Launching with `--galaxy` opens the galaxy in a newly launched instance.
- Interaction remains responsive at realistic library sizes.
- Persisted user settings either remain compatible or receive an explicit migration/reset policy.

## Known platform issue

ScreenCaptureKit can fail to provide usable frames despite an apparent Screen Recording grant. Capture now starts after the window becomes visible and retries transient first-frame failures; the native ring and frosted core still preserve the experience if capture remains unavailable. Keep this fallback even if the capture path changes.
